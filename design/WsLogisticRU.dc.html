Меньше C → граница проще и плавнее. Больше C → точнее подстраивается под точки.
C — обратная сила регуляризации. Регуляризация штрафует модель за слишком большие веса. Маленький C — сильный штраф: граница спокойная, отдельные точки почти не влияют. Большой C — штраф слабый: модель старается угадать каждую точку и может переобучиться.
