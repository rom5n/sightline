Дерево решений классифицирует, задавая цепочку вопросов «да/нет» по одному признаку за раз — «$x_1 \le 2.5$?» — пока не дойдёт до листа, и отвечает классом большинства обучающих точек в этом листе. Это строительный блок [случайных лесов](#hb/RandomForestClassifier/idea) и [бустинга](#hb/GradientBoostingClassifier/idea). Глубокие деревья — хрестоматийный пример [переобучения](#hb/intro/overfitting).

## Идея {#idea}

Вспомните игру «двадцать вопросов» или схему сортировки пациентов: *Температура? → да → Кашель? → нет → Сыпь? …* Каждый вопрос делит пациентов на две группы, внутри которых они похожи сильнее, чем раньше. Хороший вопрос — тот, что отделяет больных от здоровых как можно чище. Дерево решений учит такую схему по данным: на каждом шаге оно перебирает все признаки и пороги и оставляет вопрос, после которого две получившиеся группы самые «чистые».

## Как это работает, по шагам {#steps}

1. Кладём все обучающие точки в корень.
2. Для каждого признака и каждого порога между соседними значениями делим узел на «≤ порог» и «> порог» и измеряем неоднородность двух частей (по умолчанию — Джини).
3. Оставляем разбиение с наименьшей взвешенной неоднородностью. Создаём два дочерних узла.
4. Повторяем для каждого потомка, пока узел не станет чистым или его не остановит ограничение (`max_depth`, `min_samples_split`, `min_samples_leaf`).
5. Для предсказания проводим точку от корня вниз, отвечая на вопросы, и возвращаем доли классов в листе, куда она пришла.

**Пример.** Шесть точек на одной оси: $x = 1, 2, 3, 4, 5, 6$ с классами $0, 0, 1, 1, 1, 0$. В корне по три точки каждого класса: Джини $= 1 - (0.5^2 + 0.5^2) = 0.5$.

Возможные пороги — посередине между соседями:

| разбиение | классы слева | классы справа | Джини слева | Джини справа | взвешенно |
|---|---|---|---|---|---|
| $x \le 1.5$ | 0 | 0 1 1 1 0 | 0 | 0.480 | 0.400 |
| $x \le 2.5$ | 0 0 | 1 1 1 0 | 0 | 0.375 | **0.250** |
| $x \le 3.5$ | 0 0 1 | 1 1 0 | 0.444 | 0.444 | 0.444 |
| $x \le 4.5$ | 0 0 1 1 | 1 0 | 0.5 | 0.5 | 0.500 |
| $x \le 5.5$ | 0 0 1 1 1 | 0 | 0.480 | 0 | 0.400 |

Например, в правой части разбиения $x \le 2.5$ три единицы и один ноль: $1 - (0.75^2 + 0.25^2) = 0.375$, с весом $4/6$ получаем $0.25$. Дерево выбирает $x \le 2.5$. Затем правый потомок $\{1, 1, 1, 0\}$ делится по $x \le 5.5$ на $\{1, 1, 1\}$ и $\{0\}$ — оба чистые. Итог: два вопроса, три листа, 100 % точности на обучении.

## Формулы {#formulas}

Неоднородность узла, в котором доли классов $p_1, \dots, p_K$:

$$\text{Gini} = 1 - \sum_{k=1}^{K} p_k^2, \qquad \text{entropy} = -\sum_{k=1}^{K} p_k \log_2 p_k$$

Качество разбиения узла $N$ на левую часть $L$ и правую $R$ (дерево максимизирует это снижение):

$$\Delta = I(N) - \frac{|L|}{|N|} I(L) - \frac{|R|}{|N|} I(R)$$

Предсказание для точки, попавшей в лист $\ell$:

$$p(y = k \mid \mathbf{x}) = \frac{\#\{\text{обучающих точек класса } k \text{ в } \ell\}}{\#\{\text{обучающих точек в } \ell\}}$$

- $I(\cdot)$ — Джини или энтропия узла; $|N|$ — число обучающих точек в нём.
- В scikit-learn `criterion='log_loss'` — то же самое, что `'entropy'`.

## Где работает и где нет {#where}

**Работает хорошо**

- Когда правила должны читать и проверять люди: кредитные решения, сортировка пациентов, инструкции по поиску неисправностей.
- Смешанные признаки в любых масштабах: порогам не важны единицы, масштабирование не нужно.
- Взаимодействия («только если молод *и* курит») учитываются сами собой.

**Не справляется или вводит в заблуждение**

- Глубокие деревья запоминают шум: на обучении 100 %, на тесте гораздо меньше. Ограничьте `max_depth` или увеличьте `min_samples_leaf`.
- Неустойчивость: несколько изменённых точек могут дать совсем другое дерево — это исправляют леса и бустинг.
- Границы всегда состоят из ступенек вдоль осей; диагональной границе нужно много мелких ступенек.

## Параметры {#params}

| параметр | что задаёт | по умолчанию | увеличить | уменьшить |
|---|---|---|---|---|
| `max_depth` | самая длинная цепочка вопросов | `None` (расти до чистоты) | подробнее границы, сильнее переобучение | дерево проще, граница глаже, может недообучиться (глубина 1 — «пень») |
| `criterion` | как измеряется неоднородность | `'gini'` | `'entropy'` / `'log_loss'`: немного другие разбиения, обычно похожий результат | — |
| `min_samples_split` | минимум точек, чтобы делить узел | `2` | маленькие узлы не делятся: дерево меньше | — |
| `min_samples_leaf` | минимум точек в листе | `1` | каждый ответ опирается на больше точек: глаже, меньше шума | — |

В Sightline кнопка **+1 уровень** выращивает дерево на один уровень, а панель «Ошибка» показывает точность на тесте для каждой глубины — видно, где углубление перестаёт помогать.
