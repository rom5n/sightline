Метод опорных векторов для классификации (SVC) ищет границу, оставляющую **самый широкий зазор** между классами. Где пройдёт граница, решают только ближайшие к ней точки — *опорные векторы*. С *ядром* та же идея даёт изогнутые границы. Зазор и штраф `C` — прямой способ управлять [переобучением](#hb/intro/overfitting).

## Идея {#idea}

Вы прокладываете самую широкую дорогу между двумя деревнями, не задевая ни одного дома. Осевая линия дороги — граница; её обочины касаются нескольких домов с каждой стороны — это и есть опорные векторы. Все остальные дома можно двигать как угодно — дорога не изменится. Широкая дорога — осторожная и устойчивая граница: новый дом, стоящий чуть не там, где ожидалось, всё равно окажется с нужной стороны. Если несколько домов мешают, «мягкий» вариант разрешает дороге пройти по ним — за плату, которую задаёт `C`.

## Как это работает, по шагам {#steps}

1. Записываем границу как $\mathbf{w}^\top\mathbf{x} + b = 0$; края зазора — $\mathbf{w}^\top\mathbf{x} + b = \pm 1$, поэтому ширина зазора $2/\lVert\mathbf{w}\rVert$.
2. Широкий зазор — это малая $\lVert\mathbf{w}\rVert$ при условии, что точки остаются с правильной стороны; точки внутри зазора или не с той стороны платят штраф, пропорциональный глубине нарушения ($\xi_i$), с весом `C`.
3. Это выпуклая квадратичная задача; libsvm решает её в *двойственной* форме, которая даёт каждой обучающей точке вес $\alpha_i$. В модели остаются только точки с $\alpha_i > 0$ — опорные векторы.
4. Для изогнутых границ каждое скалярное произведение $\mathbf{x}_i^\top\mathbf{x}$ заменяют ядром $K(\mathbf{x}_i, \mathbf{x})$ — например ядром RBF, мерой сходства, которая убывает с расстоянием. Это то же самое, что прямая граница в гораздо более богатом пространстве признаков, которое никогда не вычисляется явно.
5. Класс предсказывается по знаку значения решения $f(\mathbf{x})$. Sightline закрашивает фон сигмоидой от $f$ (в scikit-learn 1.9 `probability=True` устарел).

**Пример.** Шесть точек: класс 0 в $(1, 2), (2, 3), (2, 1)$; класс 1 в $(4, 3), (5, 4), (4, 1)$. Линейное ядро, большое $C$ (практически жёсткий зазор).

- Самая широкая дорога вертикальна: граница $x_1 = 3$, то есть $\mathbf{w} = (1, 0)$, $b = -3$.
- Края — $x_1 = 2$ и $x_1 = 4$: ширина зазора $2/\lVert\mathbf{w}\rVert = 2$.
- scikit-learn оставляет два опорных вектора, $(2, 1)$ и $(4, 1)$, с $\alpha_i y_i = -0.5$ и $+0.5$.

Значение решения для $q = (2.5, 2)$ только по опорным векторам:

$$f(q) = -0.5\,\langle(2, 1), q\rangle + 0.5\,\langle(4, 1), q\rangle - 3 = -0.5 \cdot 7 + 0.5 \cdot 12 - 3 = -0.5$$

Отрицательное — значит класс 0, то же, что $\mathbf{w}^\top q + b = 2.5 - 3 = -0.5$. Если сдвинуть точку $(1, 2)$ куда угодно левее, модель не изменится вовсе.

## Формулы {#formulas}

Прямая задача с мягким зазором:

$$\min_{\mathbf{w}, b, \xi}\; \frac{1}{2}\lVert\mathbf{w}\rVert^2 + C\sum_{i=1}^{n}\xi_i \quad\text{при}\quad y_i(\mathbf{w}^\top\phi(\mathbf{x}_i) + b) \ge 1 - \xi_i,\ \ \xi_i \ge 0$$

Функция решения из двойственного решения:

$$f(\mathbf{x}) = \sum_{i \in \text{SV}} \alpha_i y_i\, K(\mathbf{x}_i, \mathbf{x}) + b, \qquad 0 \le \alpha_i \le C$$

Ядра: линейное $K = \mathbf{x}^\top\mathbf{x}'$; RBF $K = \exp(-\gamma\lVert\mathbf{x} - \mathbf{x}'\rVert^2)$; полиномиальное $K = (\gamma\,\mathbf{x}^\top\mathbf{x}' + r)^{d}$. При `gamma='scale'` $\gamma = 1/(d \cdot \operatorname{Var}(X))$.

- $y_i \in \{-1, +1\}$; $\xi_i$ — насколько точка $i$ нарушает зазор; $\phi$ — отображение признаков, заданное ядром.
- $d$ в `'scale'` — число признаков; $\operatorname{Var}(X)$ — дисперсия всех значений признаков вместе.
- Больше двух классов: scikit-learn обучает по одному SVC на каждую пару классов (один против одного), и они голосуют.

## Где работает и где нет {#where}

**Работает хорошо**

- Небольшие и средние данные со сложными, но чистыми границами: рукописные цифры, классификация белков, сигнатуры датчиков.
- Много признаков относительно строк (текст, геномика) с линейным ядром.

**Не справляется или вводит в заблуждение**

- Время обучения растёт примерно от $n^2$ до $n^3$: после ~10 000–50 000 строк лучше линейные модели, SGD или бустинг. (Для SVC Sightline показывает индикатор прогресса и кнопку отмены.)
- Признаки нужно масштабировать: расстояние в RBF бессмысленно для разных единиц.
- `C` и `gamma` влияют друг на друга; неудачная пара даёт либо «каплю», либо выученную наизусть карту. Используйте перебор по сетке.
- Нет встроенных вероятностей.

## Параметры {#params}

| параметр | что задаёт | по умолчанию | увеличить | уменьшить |
|---|---|---|---|---|
| `C` | штраф за нарушения зазора | `1.0` | нарушений меньше: зазор уже, опорных векторов меньше, подгонка точнее, риск переобучения | зазор шире и мягче, опорных векторов больше, граница глаже |
| `kernel` | форма границы | `'rbf'` | `'poly'`: полиномиальные кривые; `'linear'`: прямая граница, быстрее всего; `'sigmoid'` | — |
| `gamma` | радиус влияния опорного вектора (RBF, poly, sigmoid) | `'scale'` | каждая точка влияет только на ближайшую окрестность: извилистая граница, переобучение | широкое влияние: гладкая, почти прямая граница |
| `degree` | степень полинома (только при `kernel='poly'`) | `3` | кривые гибче | кривые проще |
